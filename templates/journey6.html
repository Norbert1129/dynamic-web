Dynamic DNS with Cloudflare

My AWS server does not have a static IP, so every restart changes its public IP. This caused my domain to stop working unless I update the DNS manually. To solve this, I created a Bash script that automatically updates my Cloudflare DNS record.

The script:

  • gets the current public IP using curl
  • compares it with the previously saved IP
  • if the IP changed, it updates the A record via the Cloudflare API
  • saves the new IP for future checks

I also configured:

  • an A record for nnmth.com
  • a CNAME record for www ➡ nnmth.com

This way I only need to update one record. Finally, I used a corn job to run the script every 5 minutes,making the process fully automated. Through this, I learned how DNS works, how Cloudflare proxying hides the real server IP, and how to automate infrastructure tasks using Bash and APIs.
