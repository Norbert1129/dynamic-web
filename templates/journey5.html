Server Security Setup

I configured several basic security layers on my server to reduce the attack surface and improve overall protection.

Firewall (UFW) 🧱

I used UFW to allow only the necessary ports:

  • 80 (HTTP)
  • 443 (HTTPS)
  • 2222 (SSH)
All other ports are blocked by default, meaning the server is only accessible through essential services.

SSH Hardening 💻 ---- 🔗 ---- 🖥

I improved SSH security by:

  • using key-based authentication instead of passwords.
  • changing the default SSH port from 22 to 2222.
This reduces the number of automated attacks targeting the server.

Fail2ban Protection 🛡

I set up Fail2ban to monitor login attempts and automatically block suspicious IP addresses.

Configuration:

  • 3 failed login attempts.
  • within a 10-minute window.
  • results in a 1-hour ban.

This helps to protect the server from brute-force attacks.
