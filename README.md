# Dynamic Web Project (Flask) Personal Learning
This is a simple dynamic web application built with Flask.

## Features
- Multiple pages
- Template inheritance (base.html)
- Running on Linux server (Ubuntu EC2)
- Nginx + Flask setup

## Tech Stack
- Python (Flask)
- HTML / CSS
- Linux (Ubuntu)
- Nginx

## Goal
Learning full-stack development and understanding how web systems work in real environments.
